# LATROMI Facades
Pequenos projetos desenvolvidos para servir de fachada para algumas funcionalidades dos Formulários do LATROMI Low-Code Aplication Plataform.


### Facade: Google Drive
Este projeto empacota a manipulação de arquivos do Google Drive para ser usada dentro de um Formulário do Latromi.

### Facade: AWS
Este projeto empacota a manipulação de arquivos do AWS S3 para ser usada dentro de um Formulário do Latromi.

### Facade: Azure
Este projeto empacota a manipulação de arquivos do Azure Blob Storage para ser usaa dentro de um Formulário do Latromi.

### Facade: FileManager
Este projeto empacota a manipulação de arquivos no servidor, permitindo operações complexas serem executadas com segurança. Contendo os seguintes recursos:
- Mesclagem de arquivos PDFs.

### Facade: GeminiAPI
Este projeto empacota a lógica de autenticação na API Google com o escopo do Gemini.
